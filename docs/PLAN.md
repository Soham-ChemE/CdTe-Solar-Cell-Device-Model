# Rebuild plan

> The original plan for rebuilding the 2025 capstone study (written 2026-11-15). Phases 0 and 1 became [`FORENSICS.md`](FORENSICS.md); the project then moved to calibrating a measured record-class cell, the 21.4 % ZnO/CdSeTe/CdTe device described in the [README](../README.md).

## Ground rules (they apply to every phase)

1. **Every reported number is regenerated by a committed script** from a committed `.def` file. Nothing is typed into a table by hand.
2. **Every input parameter has a source.** `data/parameters.csv` lists each value with its citation and an allowed range. A parameter without a source is not used.
3. **Every layer uses its own optical data.** That means a measured absorption file, or a model based on the measured band gap, and the choice is stated.
4. **Physics checks run on every result:**
   - Voc must stay below the radiative limit for the absorber band gap.
   - Jsc must stay below the detailed-balance current.
   - Efficiency must stay below the Shockley-Queisser limit.
   - SRH recombination must be non-zero unless that is intended and stated.
   - A failed check stops the result from being reported.
5. **Layer roles follow the physics.** In a superstrate CdTe cell, the front buffer (ZnSe) collects electrons and the back layer collects holes. Names in figures and text follow that.
6. **Key results are cross-checked in Sesame** (NIST). If the two solvers disagree, that gets explained before anything is written up.

## Phase 0: environment and trust (done 2026-11-15)

- SCAPS 3.3.11 runs headless under Wine on macOS.
- The original 27.99% headline reproduces from the original file.
- SCAPS and Sesame agree on a common CdTe junction: Jsc within 0.41%, Voc within 0.9 mV, FF within 0.03 points.

## Phase 1: forensic reproduction of the original study

- Re-run all 12 original `.def` files with their original sweeps.
- Produce `docs/forensics.md`: a table of every reported number against its reproduced value, with the cause of each discrepancy. Known causes so far:
  - WS2 and PCBM give about 0.25% in their own files but were reported near 26%.
  - WO3 crashed at two thicknesses.
  - Seven files contain a 10 nm CdS-like layer named "CdTe".
- Show the effect of each setup error on its own: the CdTe doping, the 1.6 eV band gap, the defects removed, and the absorption files. This quantifies how much of the 27.99% each error contributes.

## Phase 2: calibrated CdTe baseline

- Start from the SCAPS CdTe baseline (Gloeckler, Fahrenbruch, Sites, WCPEC-3, 2003), which already reproduces measured CdS/CdTe cells of that era.
- Fit to published data from real, measured CdTe cells: certified Voc, Jsc and FF, plus J-V and EQE curves digitized from open-access papers. The "Interact CdTe measurement" files bundled with SCAPS are not usable here: their own headers say they are simulations made for a 2005 teaching workshop. Only parameters with literature ranges are allowed to move: absorber doping, bulk defect density, back-contact barrier, Rs and Rsh. Report the fit quality and how well each parameter is constrained.
- Build a modern reference: a group-V-doped CdTe absorber with parameters from published work. Check it against the certified record for this cell family (23.1%, Voc 917 mV) as a realism bound.

## Phase 3: the corrected ZnSe/CdTe study

- Stack: FTO / ZnSe (front buffer, electron side) / p-CdTe / back layer (hole side) / metal.
- ZnSe absorption from published optical constants. Interface defect layers at ZnSe/CdTe and at CdTe/back layer.
- Back layers get literature parameters and their own optics. Candidates: ZnTe (industry-relevant, absorption file bundled with SCAPS), Cu2O, Sb2Se3, NiO, and Cs2BiAgI6. Cs2BiAgI6 uses its measured 1.70 eV gap and is clearly flagged as never demonstrated in a device.
- Sweeps:
  - absorber doping and defect density
  - interface defect density
  - back-contact work function
  - buffer and back-layer thickness and doping
  - temperature, 280 to 360 K
- Compare against a ZnSe-free reference and a CdS-buffer reference.

## Phase 4: uncertainty and robustness

- Run a global sensitivity analysis (Morris screening, then Sobol indices) over the literature ranges of every uncertain input. Python generates the SCAPS scripts.
- Headline question: does the ranking of back layers survive parameter uncertainty? Report each efficiency as a range, not a single number.

## Phase 5: cross-validation

- Re-run the calibrated baseline and the best and worst back-layer cases in Sesame, which supports heterojunctions (see its tutorial 2, a CdS/CdTe cell). Report the differences.

## Phase 6: write-up

Two options, to be decided with the co-authors:

- **(a) A full paper:** a calibrated, uncertainty-aware ZnSe/CdTe back-layer study.
- **(b) A short methods note** on the modelling template the original study followed (El-Mrabet et al., J. Phys. Chem. Solids 195 (2024) 112287), testing how absorber compensation, defect-free layers and shared absorption data affect its reported 29.36%.

Either way:

- The input files and scripts are released.
- SCAPS and Sesame are cited.
- Co-authors approve before submission.
